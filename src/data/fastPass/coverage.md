# Fast Pass library coverage

The bundled list contains 139 unique vocabulary terms (including the words in
kanji questions). Matching vocabulary cards are tagged automatically on every
updated installation. The source also includes 88 component kanji characters,
but those are metadata only: standalone kanji cards are not tagged automatically.
Each explicitly listed
spelling alias is supported; readings distinguish homophones.

later book lists do seed missing vocabulary because they include definitions.
