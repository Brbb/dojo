# Fast Pass library coverage

The bundled list contains 139 unique vocabulary terms (including the words in
kanji questions) and 88 unique kanji characters. Matching library cards are
tagged automatically on every updated installation. Each explicitly listed
spelling alias is supported; readings distinguish homophones.

meanings and, for vocabulary, the supplied reading.
